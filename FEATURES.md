# MountMate — Feature Details

Every MountMate feature in full. Back to the [README](README.md).

- View all connected **external drives**
- See which ones are **mounted**
- **Mount/unmount** any drive with a click
- **Mount Read-Only**: right-click an unmounted volume to mount it read-only (protect a backup drive, inspect a damaged or NTFS drive); the row shows a "Read-only" badge. A network share gets the same protection with the "Mount Read-Only" switch in its share settings (Settings → Network Shares → Edit); it applies from the next mount, also at login and when Keep Alive reconnects
- **NFS soft mount**: the "Don’t Wait for an Unreachable Server (Soft Mount)" switch in an NFS share's settings (on for new NFS shares, off for shares saved before it existed) mounts with `soft,intr,timeo=10,retrans=3,deadtimeout=30`: when the server stops answering, Finder and apps get an error instead of freezing, and the share is unmounted after about 30 seconds (Keep Alive mounts it again once the server is back). The trade-off: a file being written at that moment can fail to save. Applies from the next mount; import/export keeps it
- **Verify Volume**: right-click a mounted external volume to verify its file system data structures with diskutil in the background (never repairs); shows a "Verifying…" status (choose "Cancel Verify" to stop it); the alert suggests First Aid in Disk Utility only when damage is found, and says "Could Not Verify Volume" with the reason when the check could not run (NTFS, volume in use, unplugged)
- **Rename Volume…**: right-click a mounted, writable external volume to give it a new name (`diskutil rename`); the name is checked first (no `/` or `:`, at most 11 ASCII characters on FAT, 15 on exFAT, judged by the mounted file system), and file systems macOS cannot rename (such as NTFS) get a clear error
- Check **free space** for drives and for mounted network shares (used / total)
- **Eject All External Disks**: one button (next to Unmount All), an optional shortcut (none by default) or a Shortcuts action unmounts and ejects every external disk (an SD card in a MacBook's built-in slot counts as one) so you can unplug them; internal disks, disk images, disks with a protected volume and disks already ejecting or with a volume still mounting or unmounting are skipped, nothing is forced, and failures are listed in one alert
- **Keyboard Shortcuts**: Unmount All with `⌘⌥⇧U` and Mount All with `⌘⇧M` by default (Eject All External Disks, Mount All Network Shares and Unmount All Network Shares have none until you record one); change them in Settings (the key shown follows your keyboard layout). A small message at the top of the screen says what a shortcut did ("Unmounted 3 volumes", "Nothing to mount", "Ejected 1 disk, 1 failed", "Mounted 2 network shares"); a share that fails also gets the same alert as the Mount All / Unmount All buttons of the Saved Network Shares header
- **Keyboard and VoiceOver**: rows in the popover take keyboard focus (Tab, Up/Down; Return or Space mounts or unmounts a volume, or expands or collapses a disk, on macOS 14+), VoiceOver gets row actions, and animations stop with Reduce motion
- **Block USB Auto-Mount**: stop selected disks from mounting when plugged in or at login; **Block at Startup** (optional) also writes a rule to `/etc/fstab` and asks for your admin password
- **Custom mount point**: mount a volume at a path you choose (right-click → Custom Mount Point…), or a network share at an empty folder you choose (a folder with files is refused, so they are never hidden). Only APFS, HFS+, exFAT and FAT volumes: NTFS and disks of third-party drivers (Paragon, Tuxera, macFUSE) are refused, because an `/etc/fstab` rule would change how macOS mounts them. Settings → Management lists every custom mount rule in `/etc/fstab`, also ones MountMate no longer has saved ("Not tracked by MountMate"), so they can be removed
- **Encrypted APFS volumes**: unlock them from MountMate, with the password optionally saved in the Keychain ("Forget Saved Password" in the right-click menu removes it); Keep Alive, Mount Again on Wake and Mount All use a saved password silently
- **RAID**: Apple RAID sets show up as one disk instead of their members
- **Display options** (Settings → General → Display): **Show Count in Menu Bar** puts the number of mounted volumes and shares (protected volumes not counted) next to the icon; **Show Internal Disks** lists the Mac's own disks too; **Show Only Volumes** hides the disk rows and lists just the volumes; **Hide EFI Partitions**
- **Ignore, Protect, Pin**: right-click a volume to **Ignore** it (hide it, for example system partitions), **Protect** it from "Unmount All" and the sleep unmount, or **Pin to Top** to list it first; review the lists under Settings → Management
- **Network Shares**: Auto-mount SMB, NFS and WebDAV (Nextcloud, Synology) shares at login (existing AFP shares supported with deprecation notice); with Keep Alive off, a login share that fails because the network or the NAS is not up yet is retried after 15 s, 30 s, 1 min, 2 min and 2 min and when the network comes up (up to 5 times in all), and with Notifications on a share that still fails gets one "Could Not Mount at Login" notification with the reason; "Browse Network…" in the share sheet lists SMB and NFS servers found on the local network and fills in the host name each one announces (for example `My-NAS.local`, with the port when it is not the default). Import Mounted adds every SMB, NFS or AFP share currently mounted in Finder. The ⇅ menu next to it exports the saved shares to a JSON file and imports such a file on another Mac: passwords are never written (add them again by editing each share), shares already saved or not valid are skipped and counted. The "Saved Network Shares" header has Mount All and Unmount All buttons (each shown only when a saved share needs it) that act on every saved share at once; one alert lists each share that failed with its reason and offers Force Unmount when that may help. The server field takes a host name, IPv4 or IPv6 address (a link-local zone such as `fe80::1%en0` works) with an optional `:port`; two shares on different ports of one server (for example `nas:445` and `nas:4450`) are separate shares. A password is used and saved only with a username: without one, MountMate connects with the Mac's saved login or as a guest
- **Keep Alive**: Auto-reconnect shares and volumes when they drop, after network changes, on wake, and at login; a share or volume that is waiting shows when the next try is and a "Reconnect Now" button (also in its right-click menu) that retries right away. While a reconnect is pending, the menu bar icon shows a Wi-Fi badge (VoiceOver: "Reconnecting"). A share that is still mounted but stops responding (the NAS restarted, Wi-Fi or VPN changed) is unmounted and mounted again instead of hanging Finder; Keep Alive gives a share 10 seconds to answer, and in Low Power Mode it checks half as often. When the server rejects a share's saved password (for example after it was changed on the NAS or in the Windows domain), Keep Alive and the login retries stop trying it, so the account is not locked by repeated sign-ins: the share shows "Password Rejected" in Settings → Network Shares until you edit it or mount it yourself, and with Notifications on you get one "Password Rejected" notification
- **Copy Path / Open in Terminal**: right-click a mounted volume or network share to copy its mount path or open a Terminal window in that folder
- **Unmount All Disks on Sleep** (Settings → General → Behavior): unmount every external disk before the Mac sleeps; Time Machine disks and disk images stay mounted. **Mount Again on Wake** (on by default, shown when the sleep unmount is on) mounts those disks again after wake; disks you unmounted or ejected yourself, disks that were unplugged and blocked disks stay unmounted. With notifications on, you are told about disks that could not be unmounted before sleep and about disks that were not mounted again (still disconnected or failing about 45 seconds after wake)
- **Unmount All Disks When the Screen Locks** (Settings → General → Behavior, off by default): unmount every removable disk as soon as the screen locks, so no drive stays open while you are away. Time Machine disks, disk images, protected volumes, volumes kept mounted by Keep Alive and volumes in use stay mounted, nothing is forced and no alert appears. With **Mount Again on Wake** on, the disks are mounted again when you unlock (not at wake while the screen is still locked)
- **Also Unmount Network Shares** (Settings → General → Behavior, off by default, available when the sleep or lock unmount is on): unmount your saved network shares too when the Mac sleeps or the screen locks, the same way as a manual Unmount, so none goes stale across sleep or a Wi-Fi change. Shares kept mounted by Keep Alive and shares in use stay mounted, nothing is forced, and a failure never holds back the disks. With **Mount Again on Wake** on, exactly those shares are mounted again on wake or unlock (saved Keychain password); a share you unmounted yourself stays unmounted.
- **Open in Finder after mounting** (Settings → General → Behavior, off by default): a volume or share you mount from the popover (Mount, Mount Read-Only), with Mount All or with a Shortcuts action opens in a Finder window once it is mounted. Disks mounted when plugged in, at login, by Keep Alive or after wake never open a window, and neither do failed mounts or blocked disks.
- **Unmount When Idle**: Per volume on an external drive (right-click → Unmount When Idle), unmount it after 1–60 minutes without reads or writes on its disk; never forced, so a volume in use stays mounted and is tried again after another idle period; off while the volume is protected or kept mounted
- **Almost-full warning** (Settings → General → Behavior; on by default, from 80%, 90% or 95% used): a mounted volume or network share at or above the limit gets an orange "Almost full" badge and ring (hover or VoiceOver: "Almost full: 94% used, 12 GB free"); with Notifications on you also get one notice per volume or share, and another only after it drops 5 points below the limit and fills up again. Mounted external volumes are checked every 15 minutes, so a drive that stays plugged in is reported even while the menu stays closed. Disk images, system volumes, read-only volumes, volumes under 1 GB (boot partitions such as VTOYEFI, full by design) and shares that report no size are skipped, and nothing is unmounted or deleted. To silence one volume, right-click it and choose "Don't Warn About Free Space on This Volume" (same menu to turn it back on).
- **SMART warning**: a disk whose own health check (`diskutil` SMART status) says "Failing" gets a red warning triangle next to its name (hover or VoiceOver: "SMART status: failing — back up this disk"); with Notifications on you also get one notice per disk. Drives that report Verified, Not Supported or nothing show nothing, and MountMate never unmounts or ejects a disk because of it.
- **Notifications** (optional, off by default; Settings → General → Behavior): get told when Keep Alive cannot reconnect a mount and when it is back (once per outage, not on every retry), when a blocked disk could not be unmounted, when unmounting before sleep ran out of time, and when a volume was unmounted because it was idle. Clicking a notification opens MountMate, and the "Cannot Reconnect" one has a "Reconnect Now" button.
- **Disconnected without ejecting** (off by default; shown under Notifications when they are on): a notice when a USB drive or memory card is pulled out while one of its volumes is still mounted (“Backup” was disconnected without being ejected. Check your files.), so you can check that a copy finished. Volumes unmounted or ejected first (MountMate, Finder, `diskutil`), disk images, internal disks, Time Machine volumes and disks that vanish while the Mac sleeps or just after it wakes are not reported.
- **Shortcuts**: the Shortcuts app (and Spotlight, Siri, Automator via "Run Shortcut") gets thirteen actions: Mount All Volumes, Unmount All Volumes, Eject All External Disks, Mount All Network Shares and Unmount All Network Shares (every saved share), Mount Network Share and Unmount Network Share (pick any saved share), Mount Volume and Unmount Volume (pick a volume or type its name; case is ignored, an unknown name is an error, a protected volume is not unmounted; volumes with the same name, such as two "Untitled" drives, are listed apart with their size and device and the action keeps the one you picked), and Eject Volume (ejects the external disk holding the volume you pick or name; a disk with a protected volume is refused and nothing is forced). Mount Volume and Mount Network Share return the mount point as text ("/Volumes/Backup", "/Users/you/mountmate/NAS"), ready for Run Shell Script (rsync) or a path field. Three actions only read state: Get Mounted Volumes (the mounted external volumes, in menu order), Get Network Shares (every saved share) and Is Volume Mounted (true or false; a volume that is not plugged in is not mounted), and each volume or share they return has Mounted and Mount Point details, so a shortcut can branch with If. These three have no Siri phrase (macOS allows an app ten); find them in the Shortcuts action list. Build "arrive home → mount the NAS", "mount the NAS → rsync to it → unmount" or "before bed → unmount all" automations; a failure is shown as the shortcut's error. Needs MountMate to be installed; it starts in the background when a shortcut runs
- **Force Eject**: Safely force eject drives that are in use; the alert names what keeps the drive busy in plain words (Spotlight indexing, Quick Look, Time Machine, Finder…) with its icon
- **Force Unmount for network shares**: if ejecting a share fails because it is busy or its server is gone, MountMate explains why (translated) and offers a confirmed Force Unmount
- **VoiceOver**: icon-only buttons and the menu bar icon are announced by name; the keyboard shortcut buttons in Settings are named by their action and start recording with Space, Return or VoiceOver's press
- **Localized** in 7 languages, with correct plural forms
- Runs quietly in the **menu bar**
- **Copy Diagnostics** (Settings → General → Logs): puts the MountMate and macOS versions, your settings (incl. Keep Alive interval and low-space threshold), disk counts by connection and file system and the last hour of MountMate's log on the clipboard for a bug report, without passwords, paths, or disk and share names (see [Sending Logs](README.md#-sending-logs))
- **Quiet update reminders**: an update found by an automatic check never opens a window over your work: the menu bar icon gets a dot (VoiceOver: "Update available") and the popover shows "MountMate X.Y is available — View…"; click View… to open the update window. Check for Updates… still opens it right away
- Fully native – no Electron; the only dependency is [Sparkle](https://sparkle-project.org), used for automatic updates (Settings → About & Updates, where you can switch automatic checks off; the popover header has a Check for Updates button)
